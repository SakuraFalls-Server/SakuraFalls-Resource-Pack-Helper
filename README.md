# resouce-pack-helper

## About

This repository contains our custom resource pack helper tool that modelers can use to add their work 
to the resource pack without it being a difficult and tedious endeavor.  

Note that this tool is specifically designed for our server, SakuraFalls. Other servers will likely not 
find this tool useful.
